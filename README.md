# States-Effects Tomography — Finite Criteria for Simplicial States and Local Tomography

This repository contains the source of the Cosmochrony paper
*Finite Criteria for Simplicial States and Local Tomography toward Emergent Operational Composition*,
a working paper of the **non-injective foundations sub-programme**, companion to
[Effective Composition](https://cosmochrony.org/science/non-injective/effective-composition/).

## Central Question

The companion paper characterises, for a finite substrate without a supplied subsystem factorisation, the
possibilistic support layer completely and the preparation layer for two reference classes, and explicitly
leaves open the **states-and-effects layer**: the construction of effect spaces, their bilinear pairing with
states, local tomography, and any quantum tensor product.
This paper resolves that layer's finite, mono-system, and bipartite-composition content, importing the
rank-one cylindrical-conditioning family exactly as the companion paper's Theorem 3 supplies it.

> Which parts of the state-effect-tomography package does a finite, rank-one admissibility contract supply
> for free, and which require an explicitly typed, separately motivated import?

## Core Results

- **Primitive convexity obstruction.**
  The raw cylindrical-conditioning family is finite while its own convex hull is a continuum, for any local
  outcome set of size at least two, with no genericity hypothesis; conditioning inside a projection fibre
  does not rescue this for free.
- **Simplicial closure under classical randomisation.**
  An explicit postulate (P1) closes the family onto the full probability simplex, locally and jointly,
  independently of the reference measure's rank.
- **Representation vs.\ availability of effects.**
  Affine effects on a simplex correspond bijectively to a cube of vectors — a bookkeeping fact, not a
  physical claim; a weak coarse-graining axiom already yields the full Boolean effect algebra; the full
  continuum of effects needs a further, dual randomisation postulate (AX-RND), realised by an explicit
  multilinear reconstruction.
- **Independence and consistency of the two randomisations.**
  P1 and AX-RND are logically independent; a common classical control resource reproduces both only under an
  explicit independence clause between its two interfaces — dropping it breaks bilinear consistency, by an
  exact numeric witness.
- **Uniqueness of the composed effect.**
  Given physical existence of a bipartite effect (AX-COMP) and compatibility with joint Dirac states, it is
  forced to equal the pointwise-product formula: no tensor product is imported to define it.
- **Inaccessible joint effects.**
  Local composition reaches only rectangle effects, strictly fewer than all joint sharp effects (exactly 10
  of 16 for two-outcome sides); a CHSH-shaped separating witness shows this survives full local
  randomisation.
- **Exact criterion for local tomography.**
  Local tomography holds exactly when each side's effect family linearly spans its ambient space — strictly
  stronger than merely separating its own simplex — equivalently, when it separates states and its linear
  span contains the unit effect.

This paper derives no Born rule, no quantum state geometry, and no phase or interference structure: every
closure beyond the forced discrete/Boolean skeleton is obtained only under an explicitly typed postulate,
never from the admissibility contract or the simplicial geometry alone.

## Reproduction

All numerical claims are reproduced by six deterministic scripts using exact rational arithmetic
(`fractions.Fraction`) and no dependencies beyond the Python standard library:

```bash
python3 code/convexity_obstruction_tests.py   # primitive convexity obstruction
python3 code/simplicial_closure_tests.py      # simplicial closure under P1
python3 code/affine_effects_tests.py          # representation, Boolean skeleton, full cube
python3 code/cc_unification_tests.py          # P1/AX-RND independence and CC-IND witness
python3 code/bipartite_composition_tests.py   # uniqueness, rectangle census, CHSH-type witness
python3 code/local_tomography_tests.py        # exact tomography criterion and its corollary
```

No randomness is involved; every number in the paper is regenerated exactly.
The full build (figure generation under the pinned environment, checksum verification, then LaTeX
compilation) is:

```bash
pip install -r code/requirements.txt
bash build.sh
```
